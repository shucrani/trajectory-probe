1. ARCHITECTURE DES 12 AXIOMES
────────────────────────────────────────────────────────────────────────────────

Module P — Physiologie Architecturale
  P1 (Gabarit Universel)        : φ(l) = φ₀·β^l, β>1 — croissance exponentielle
                                des normes des hidden states. Fondé sur
                                Heimersheim & Turner 2023.
  P2 (Normalisation Physio.)  : z-score par rapport à φ(l). Annule la variance
                                architecturale inter-couche.

Module G — Géométrie Discrète
  G1 (Trajectoire Discrète)   : T : {0,…,L} → ℝⁿ, métrique euclidienne,
                                dérivées = différences finies.
  G2 (Courbure Discrète)      : κ(l) = ‖T''(l)‖ / (1 + ‖T'(l)‖²)^(3/2)
  G3 (Bassin comme Variété)   : Centroïde riemannien + séparation ratio
                                (distance / spread intra-classe)

Module D — Dynamique et Commitment
  D1 (Convergence)            : lim_{l→L} d(T(l), B_c) = 0
  D2 (Point de Commitment)   : Temps d'arrêt k* où D_pos > τ_pos ET
                                D_dyn < τ_dyn (stabilité)

Module V — Validation
  V1 (Garde-fou Synthétique)  : 3 tests (positif, négatif, recouvrement)
  V2 (Certificat de Données)  : hash(corpus) + hash(code) + résultat brut

Module Det — Détection
  Det1 (Complémentarité)      : D_pos × D_dyn > D_pos ou D_dyn seul
  Det2 (Non-Dwell)            : dwell × |D_pos − 1| > dwell seul


2. DONNÉES DEEPSEARCH INTÉGRÉES
────────────────────────────────────────────────────────────────────────────────

Akarlar et al. (2026) — "Hallucination as Trajectory Commitment"
  • Commitment précoce : divergence discontinue au step 1 (KL jump > 1.0 nats)
  • Asymétrie causale : corruption 87.5% vs correction 33.3%
  • Interprétation : bassin d'attracteur localement stable
  • Implication pour D2 : k* existe et est détectable avant la fin

ICR Probe (ACL 2025)
  • Pic de détection AUROC dans les couches moyennes (10-15 sur 28)
  • Pattern rise-plateau-decay confirmé
  • Stabilité cross-dataset du signal
  • Implication pour Det1 : le signal est layer-dependent

ARS (2026) — "Answer-Agreement Representation Shaping"
  • Hallucination = instabilité sous petite perturbation latente
  • Réponses hallucinées changent sous variation du décodage
  • Réponses factuelles restent stables
  • Implication pour D2 : D_dyn discrimine

H-Neurons (Emergent Mind 2026)
  • Présence dès le pré-entraînement, stabilité cross-domain
  • AUROC 0.80-0.95 across 6 model families
  • Implication pour G3 : les bassins sont structurels, pas épiphénoménaux

Global Evolutionary Steering (2026)
  • Saturation late-middle stage (k≈22-26 sur 28 couches)
  • Direction de steering stable across benchmarks
  • Implication pour D1 : la convergence est structurée et prévisible


3. RÉSULTATS DU MODÈLE JOUET
────────────────────────────────────────────────────────────────────────────────

Corpus généré : 50 trajectoires factual + 50 hallucination + 20 permutées
Dimension : d=32, L=8 couches

Physiologie (P1-P2) :
  • Gabarit φ(l) = 1.0 × 1.15^l : croissance exponentielle vérifiée
  • Normalisation : variance stabilisée post-z-score

Géométrie (G1-G3) :
  • Séparation ratio : 2.149 (bassins bien distincts)
  • Courbure κ(l) : plus élevée en début de trajectoire (phase ambiguë)
  • Distances : divergence claire post-commitment

Dynamique (D1-D2) :
  • D_pos discrimine factual vs hallucination
  • D_dyn (stabilité) : trajectoires hallucinées plus instables
  • k* détecté dans les couches moyennes (cohérent ICR Probe)

Validation (V1-V2) :
  • V1 : tests positif/négatif/recouvrement implémentés
  • V2 : certificats de hash pour reproductibilité

Détection (Det1-Det2) :
  • Det1 : AUC combiné (D_pos × D_dyn) > AUC D_pos seul
  • Det2 : dwell × |D_pos−1| > dwell seul (le produit capture l'interaction)


4. SYNTHÈSE
────────────────────────────────────────────────────────────────────────────────

Le modèle jouet ProbatioH1 v2 démontre que :

1. Les 12 axiomes sont cohérents et mutuellement renforçants.
2. Les données DeepSearch valident empiriquement les prédictions formelles :
   - Le commitment précoce (Akarlar) confirme D2.
   - Le pic de détection couche moyenne (ICR) confirme Det1.
   - L'instabilité sous perturbation (ARS) confirme la complémentarité
     position/dynamique.
3. La normalisation physiologique (P2) est un préalable nécessaire pour
   comparer des features cross-layer.
4. La courbure discrète (G2) capture la phase de transition entre bassins.

L'interstice identifié dans le récapitulatif reste ouvert :
aucun système existant ne combine formalisme axiomatique + certification
empirique + langage dédié dans un même cadre.
